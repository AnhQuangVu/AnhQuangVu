### 🚀 Selected Projects

- 🌊 **[Floodos-hou/FloodOS](https://github.com/Floodos-hou/FloodOS)** *(2026 Vietnam Open Source Software Olympiad — DX-OS Open-Core track)*: An open-source operating system for coordinating urban flood emergency response in Hanoi.
  - Automated standard operational workflows with **BPMN 2.0** on **Flowable Engine** (SOP-01 emergency dispatch & SOP-02 breakdown recovery) with a 100-point prioritization scoring model.
  - Hardened with a **Zero-Trust Security Core**: SSO OIDC/PKCE via Keycloak, APISIX edge validation, dual-layer authorization (RBAC + Row-Level Security), ClamAV malware scanning, and a SHA-256 tamper-evident ledger.
  - Asynchronous event-driven architecture powered by **Kafka + MQTT**, **Java 21**, **PostgreSQL 16**, real-time tactical map built with **React 19 + MapLibre GL**, and an AI Copilot Assistant built with **FastAPI**.
  - 🔗 *[Source Code](https://github.com/Floodos-hou/FloodOS) &nbsp;|&nbsp; [Live Demo & Case Study](https://vuquanganh.vercel.app/#projects)*

- 💼 **[Startup-Kit-BE](https://github.com/AnhQuangVu/Startup-Kit-BE)** & **[StartupKit-fe](https://github.com/AnhQuangVu/StartupKit-fe)** *(2025 — 2026)*: A two-sided marketplace connecting startups, mentors, and social-impact investors.
  - Standardized 5 actor groups mapped to comprehensive Data Flow Diagrams (DFDs), structuring 6 core business lifecycles and verifiable acceptance criteria.
  - AI-driven profile generation, mentor recommendation, and investor matching algorithms.
  - High-performance RESTful APIs built with **Java Spring Boot**, **Spring Security + JWT**, **PostgreSQL**, and containerized with **Docker**.
  - 🔗 *[Backend API](https://github.com/AnhQuangVu/Startup-Kit-BE) &nbsp;|&nbsp; [Frontend UI](https://github.com/AnhQuangVu/StartupKit-fe)*
